# The Perspectiva Documentation
## `namespace pers`

The `namespace pers` contains all additions of Perspectiva for all headers, e.g. all its classes, functions, namespaces (except `pers` itself), templates, macros & declarations.

> [!WARNING]
> Any alteration to the `namespace pers` may distort the library functionality.
> Do not add or modify any elements in this namespace to avoid that. Even if it is not harmful, future versions may break.
> 
> It is also recommended not to make macros with the `PERSPECTIVA_` suffix to avoid name conflicts even outside `namespace pers`.
