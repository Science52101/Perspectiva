Perspectiva
</h1>

Perspectiva is a POSIX-only C++ header library for terminal ASCII[^1] and CUI manipulation from [Science52101](https://science52101.github.io).

> [!WARNING]
> This project is a work in progress! Most of it may be incomplete, unsafe or broken!

[^1] Including animations and plotting.
